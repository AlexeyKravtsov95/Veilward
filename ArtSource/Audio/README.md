# Источники звука VEILWARD AUDIO.1

Музыка, мелодический материал и SFX созданы специально для VEILWARD 25.11.2026 с помощью Codex. Редактируемый исходник — [render_audio1.py](render_audio1.py). Скрипт содержит партитуру, тембры, огибающие, микс и детерминированный seed 490607. Синтез использует Python standard library. Внешних сэмплов, исходных записей, музыкальных цитат, сервисов генерации аудио и связанных лицензий нет. Все экспортированные файлы предназначены для использования и поставки с проектом VEILWARD на условиях проекта.

Воспроизведение из корня checkout:

```bash
python3 ArtSource/Audio/render_audio1.py
```

Команда пересобирает 50 PCM16 WAV, включая два стереоцикла 48 кГц, 26,24/20,48 с, и 48 mono SFX 48 кГц. Атаки и попадания шести стихий имеют две вариации. Воспроизводимая вариация меняет seed шумового слоя и часть строя резонаторов. Огибающие на краях SFX доводятся до нуля. Хвосты струн, отражений и колокольчиков распределены циклически вокруг музыкальной границы.

В Unity команда **Veilward → Audio → Reimport Audio Catalog** валидирует группы и пересобирает ссылки. Музыка использует stereo Vorbis, Streaming, quality 0,78. SFX используют mono ADPCM, Decompress On Load, target 32 кГц, preloaded. Runtime загрузка не читает исходники из ArtSource. Исходный максимум −4,44 dBFS, уровни в Unity дополнительно ограничены на каждом слоте. [Матрица мотивов и событий](../../Docs/AUDIO1.md).
