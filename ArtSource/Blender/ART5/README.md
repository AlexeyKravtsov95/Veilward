# ART5 — оригинальные противники

23.11.2026; авторинг AI-assisted в OpenAI Codex, GPT Sol6.1 High по задаче46 владельца. Входы: текст issue46, собственные GDD/ART1 palette и direction. Внешние изображения/модели/аниме-персонажи/звуки не использованы. Геометрия и ключи созданы author_enemies.py, затем сохранены как редактируемые Blender sources; redistribution в составе VEILWARD, отдельной сторонней лицензии нет. Юридическая оценка оригинального AI-assisted content остаётся владельцу; provenance не является гарантией исключительных прав. Image-generation service/seed/job не применялись.

Два .blend, два FBX, по4rigid moving meshes,5clips Idle/Move/Hit/Death/Leak. Без armature/skin weights. Сегментированный дух/броня намеренно допускают rigid articulation. Source ground pivot0/meters; части имеют осмысленные собственные pivots. Palette UV reuse ART1; два разных shared materials на модель. Фактические суммарные slots Shade5/boss8, stencil дополнительно4renderers/модель с теми же meshes; HP источники/2cues прежние. Нет material instances/новых textures.

`author_enemies.py` — полное воспроизведение оригиналов; не запускается для обычных правок. Редактируйте source, сохраняйте, затем Blender `--background <source> --python-exit-code 1 --python export_enemies.py`. Экспорт только двух собственных FBX. Конверсия FBX axis_forward=-Z/axis_up=Y, meters/FBX_SCALE_UNITS, mesh normals, triangulate, baked full113frame take30Hz. Unity importer bakeAxisConversion/globalScale1/useFileScale, Legacy/no compression, explicit5ranges0–30/31–61/62–74/75–93/94–112. No physics/root motion; automatic Animation disabled. Pose samples исполняются вручную только presentation active clock.

`check_sources.py` открывает сохранённые sources и проверяет actual units/triangles/UV/normals/positive volumes/4parts/материалы/9curves×113keys начасть. `verify_reexport.py` требует exact2source names, реально экспортирует оба и сравнивает Unity8meshes/10clips, все keyframes и четыре sampled poses/clip, GUID/remaps/dependencies. Runtime rootY.6; Shade legacy root scale.6 компенсируется только orientation child localY=-1/scale1.666667; bossroot1→localY-.6/scale1. Source static vertices hover.08–.18m; фактические Unity rest-pose Renderer bounds minY Shade.058384/boss.157247m из-за rotation артикулированных частей; обе модели над ground, без изменения root/UI. Исторический ART1 source не меняется.
