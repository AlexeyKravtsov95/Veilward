# P2.2 Steam/Storm & Hybrid Towers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Каждый следующий PR начинается от свежего main после review/merge предыдущего. Этот документ не даёт разрешения начать игровую реализацию.

**Goal:** После утверждения спецификации добавить две ограниченные реакции, два гибрида и читаемый graybox с доказанными deterministic/economy/checkpoint guarantees.

**Architecture:** Pure C# Domain синхронно разрешает реакцию внутри primary attack; отдельные transient события сообщают причину и фактический damage. Существующий каталог/typed economy расширяются optional intrinsic payload; JSON schema 2 остаётся safe-wave. Presentation отражает события и snapshots, не исполняет бой.

**Tech Stack:** Unity **6000.3.28f1 (8f082d2fe476)**, C#, текущие ScriptableObject/uGUI, NUnit EditMode/PlayMode, существующий WaveCheckpointStore. Новых зависимостей нет.

**Spec:** [P2.2A_REACTIONS.md](P2.2A_REACTIONS.md), база `5e8f541` (merged PR #17).

## Global Constraints

- **До P2.2b:** владелец явно утверждает P-01…P-07 спецификации; числа остаются гипотезами даже после согласования implementation contract. P2.2a — только документы.
- Fixed simulation **30 Hz**, Domain `noEngineReferences: true`, без RNG/Unity/physics в targeting; pure-C# damage/death/reward. Все новые `.cs` сопровождаются `.meta`.
- Не менять Unity/URP/packages, базовые FLAME/TIDE/GALE/STONE и legacy stats, Shade/волны/награды/стартовые ресурсы; не вводить unlocks P2.3 или другие реакции.
- Steam/Storm cooldown **60 ticks**, per-enemy/per-kind для primary и secondary; Steam radius **1.25**, total cap **4**, damage **100%**; Storm hop range **2.0**, additional cap **2**, damage **75%** — гипотезы spec §3–4. Гибриды строго по таблицам §6.
- `AttackEvent.Damage` остаётся configured base, WasLethal direct-only. Новые ReactionEvent/DamageResolvedEvent не управляют экономикой, не сериализуются и очищаются после каждого Step.
- Schema **2**, прежние content IDs и physical slots, schema 1 → test-tower. Interrupted Combat целиком откатывается к Preparation; одинаковый replay гарантируется внутри одного ruleset, не между P2.1/P2.2.
- Не более **двух** overhead markers; Pause замораживает simulation/VFX, Resume без catch-up/click-through; tests используют temporary save root.
- Каждый PR: specification/regression → failing tests → minimal implementation → positive full gates/evidence → PR → независимое review. Self-merge и release без approval запрещены.

## Review Focus

Пять наиболее рискованных условий и назначенные проверки:

1. Истечение complement или lethal в тот же tick: никакого ghost proc; REG-134/135 в P2.2c.
2. Вторичный victim становится инициатором позже того же tick: общее окно, независимость видов и TowerId; REG-137/138 в P2.2c.
3. STORM без соседа, смерть промежуточной цели, equidistant chain/изгиб пути: корректные no-proc/visited/Euclidean boundaries; REG-140/141 в P2.2c.
4. Старый schema 2 с новыми правилами и unknown-type primary с валидным backup: state compatibility, rejection без mutation; REG-151/152 в P2.2d.
5. Смерть primary после нелетального direct и несколько Steps до render: direct-only WasLethal, captured positions, cleanup и одна награда; REG-143/145 в P2.2c, REG-157 в P2.2e.

### Task 1 / PR P2.2b — Definitions и additive event contract

**Files:** карта P2.2b; Create `Assets/_Game/Tests/EditMode/BattleReactionDefinitionTests.cs`; Modify `Docs/REGRESSION.md` REG-128…131. Config assets/scene/Infrastructure/BattleSimulation не входят.

**Interfaces (Produces):**

```csharp
enum ReactionKind { Steam, Storm }
// Все properties read-only, constructors валидируют и копируют входные коллекции.
ReactionPayload(ReactionKind kind, int damagePercent, float range, int targetLimit)
// Kind, DamagePercent, Range, TargetLimit; Steam limit включает primary, Storm — только соседей.
ReactionDefinition(ReactionPayload payload, int cooldownTicks, int priority)
ReactionCatalog(IReadOnlyList<ReactionDefinition> definitions)
// static ReactionCatalog.Empty; TryGet(ReactionKind, out ReactionDefinition); Get(ReactionKind)
```

`TowerDefinition` получает последний optional parameter `ReactionPayload intrinsicReaction = null`, property `IntrinsicReaction`; старые вызовы компилируются. Гибрид без соответствующего global reaction definition будет отклонён при сборке simulation в P2.2c/d.

События — immutable structs с полями/семантикой spec §5; `ReactionTriggerKind { StatusPair, Intrinsic }`, `DamageOrigin { Direct, Burn, Reaction }` разместить в соответствующих event файлах. SourceTowerId хранится даже у исчезнувшего источника Burn. Никакого new event не публикуется на этом этапе.
