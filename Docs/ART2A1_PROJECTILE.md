# ART.2a.1 revision 2 — визуальный огненный снаряд (#73 / PR74)

19.11.2026. Владелец заменил требование короткого луча/импульса: нужен отдельный летящий сгусток. Старый вид ba87f0f не принят. Продолжаем тот же Draft PR74, сохраняем проверенные Shade/HP и неизменную Domain simulation. Предварительное согласование направления уже дано.

## Scope и минимальный контракт до реализации

- Только ArtReference presentation. Компактная слоистая красно-оранжевая головка с горячим ядром реально проходит от ядра фонаря к captured TargetPosition за **6 fixed visual ticks / .2s**. Короткий рваный хвост следует непосредственно за головкой, не соединяет башню с целью. Полёт не меняет Domain damage/projectile physics/fire rate/range/Burn/rewards/content/schema/saves. Production Battle сохраняет generic beams.
- Фазы: source flash → flight → arrival/impact → decay. Impact начинается только после6ticks, затухает ещё за5ticks; полный lifetime11ticks, до следующего saved cooldown30ticks. Без нового mesh/texture source: pooled LineRenderer billboard/crossed layers существующих author-owned unlit материалов; никаких новых lights/bloom/packages/frameworks.
- **Согласование HP/death:** небольшой preallocated ring из7полных authoritative enemy snapshots, presentation delay6ticks. В ArtReference позиции, HP, появление и удаление врагов показываются на одном задержанном timeline. AttackEvent запускает снаряд сразу; на arrival отображается post-hit snapshot исходного attack tick. HP не сочиняется/не пересчитывается, Domain не мутируется. Перед lethal arrival сохраняется snapshot живого врага; на arrival он исчезает вместе с локальным impact. Burn и leaks следуют тому же задержанному timeline без fake damage.
- Captured EnemyId/target position принадлежат атаке; снаряд не держит Transform врага. Stable-ID slots врагов исключают ошибочную привязку при reuse. На arrival projectile position совпадает с captured damage point; движущаяся цель до этого проходит предыдущие authoritative snapshots. Snapshots фиксируются каждый tick, включая несколько Steps перед render; clock паузы общий. После terminal Domain snapshot clock продолжает drain, затем restart.
- HP имеют приоритет над overlay VFX: две shared material copies только в ArtReference (queue3030 против3020), прежние цвета/ratio и common health component. Никаких material allocations на атаку; copies уничтожаются с showcase. Synthetic probes используют тот же путь. Render regression сравнивает HP pixels со снарядом и без него.
- Prewarm8effects/12enemyviews; snapshot buffers выделены один раз. При заполнении effect pool — fail-fast вместо скрытого повторного удара/сброса. Restart/scene unload очищают flight/impact/snapshot IDs/очередь; повторные награды невозможны (read-only presentation). В ArtReference нет checkpoint Continue; scene re-entry — новый изолированный showcase, production Continue остаётся проверен общими tests.

## Acceptance / regression scenarios до реализации

- ART21P-01: head position меняется во время flight; начало у источника, mid-flight строго между source/target; хвост короткий и локальный. Нет статичной линии на всём отрезке. Impact false до arrival и true после него. Phase order/expiry/повторный Play/Clear не увеличивают число объектов.
- ART21P-02: реальный public saved combat nonlethal: сразу Domain HP изменён, отображённый authoritative snapshot ещё pre-hit; до arrival HP прежний, на arrival exact captured post-hit HP/position. AttackEvent.TargetEnemyId/WasLethal/TargetPosition сохранены, все event streams consumed once.
- ART21P-03: lethal: Domain удаляет врага/выдаёт награду раньше, view с тем же ID остаётся до arrival; на arrival исчезает, impact у captured position. Новый EnemyId/slot reuse не меняет старый projectile target. Full Domain trace до/после presentation совпадает с independent simulation, включая kills/gold/HP/positions/events.
- ART21P-04: Pause замораживает head/tail/impact/HP/deferred death, Resume выбрасывает первый delta; несколько fixed Steps перед render не меняют order/arrival. Restart во время flight и во время impact убирает все части/IDs/pending snapshots. Terminal drain и scene unload/re-entry не оставляют false bars/effects. Pool bounded, нет allocations на attack/tick/frame.

## Риски

Delay enemy presentation на .2s — только художественный harness, не готовая production damage feedback система. Spawn/death/HP должны быть на одном timeline, иначе попадание будет промахом/ранней смертью; snapshot tick и target ID проверяются явно. Очень короткий выстрел должен сохранять видимый полёт; исходную камеру/масштаб не увеличивать. Overlay может конкурировать с лицом врага; головка ограничена примерно .25–.35m, HP выше эффекта. Числа — visual tuning в разрешённом scope, device performance/normal-speed artistic approval отдельно.
