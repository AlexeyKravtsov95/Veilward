# ART.4 — первая production карта / #45

Исходная база: main `80d453fcbf234e46f35f6c07c5018e68c371eb7c` (merge87). Работа в существующем checkout, ветка `codex/art4-production-map`. Чужие четыре rendering/material carry-in и untracked files сохраняются побайтово; actual inputs учитываются отдельно. Исторические ART1–3 proofs не изменяются.

## Scope и решение

Закончить окружение реальной Battle: объёмный небесный остров лесного святилища, непрерывная каменная дорога, ритуальные build sockets, различимые вход и Сердце, низкие периферийные камни/растительность, спокойный фон и тёплый directional/cool ambient. Принятые нефрит/индиго/тёплый камень/бронза/коралл берутся из shared ART1 palette. Композиция делегирована владельцем в #45.

Выбран отдельный `BattleEnvironmentBuilder`: импорт ART4 kit и размещение от production map/path в Editor; runtime environment статичен. Остров — отдельные верх/скальные борта/нижние кристаллические уступы в одном editable source, повторяемые дорога/socket/props — отдельные meshes/prefabs. ART1 kit переиспользуется только где подходит, без правки исходников/исторического showcase. Декор находится вне клеток; никакого увеличения gameplay root. Прежняя graybox-плита удаляется из production builder, legacy `CreateGridGeometry/CreatePathGeometry` остаются для fixtures. Полная перепаковка ART1 исказила бы исторические proofs; giant combined level мешал бы reuse и проверке импорта.

## Неизменяемые контракты

До реализации readback из сохранённой Battle и `EightWaveAbilityBossV2.CreateSimulation()` фиксирует width/height/origin/cellSize, каждую cell/state/center, ordered path points/distance, spawn/heart, camera pose/projection/clip/viewport и world→screen→ground→cell. After должен совпасть. Числа берутся из config, не из художественного выбора. Domain X/Y отображается в Unity X/Z; towers/selection используют прежний ground convention. Ни Domain, ни content/schema/save, враги/HP/status anchors, все18 tower assets/binding, конфигурации, цены/награды/волны/босс/ability не меняются.

Только фон/свет environment могут измениться; точные дельты перечисляются в evidence. Shared palette/shaders и stencil conventions сохраняются. Без packages/features/postprocess/dynamic lights/новых textures. Декор не имеет colliders, UI или runtime scripts; высокие детали вне playable cells/path. Сокеты не закрывают selection/preview и корень tower остаётся прежним.

## Budgets/source

Editable originals `.blend` в `ArtSource/Blender/ART4`, FBX в `Assets/_Game/Art/Models/ART4`, Unity-generated meta, prefabs ART4. Meters/applied transforms/ground0/+Yup/+Zforward, palette UV, imported normals, не более2shared slots/model. Остров ≤5000tri, endpoint ≤2000tri, repeated tile/socket ≤400tri, props ≤1000tri. Фактические total geometry/renderers/materials/instances измеряются, не называются device budget PASS. Реальный повторный export из сохранённых sources и Unity readback обязан сохранить geometry/UV/normals/submeshes/GUID/remaps/refs.

## Риски и ограничения

Occlusion: кусты/скалы по краю, stencil у ближайшего декора проверяется отдельно. Площадки на96 cells нельзя спутать с путём/декором. Tests builder могут пересериализовать carry-in: pre-run backup только малых известных outputs и восстановление только собственных generated bytes с SHA audit. Actual rendering carry-in не объявляется canonical/equivalent целиком новому окружению. Raw failures сохраняются.
