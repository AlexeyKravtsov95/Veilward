## Global Constraints

- U-01…U-05 требуют утверждения владельца до P2.3b; численные стартовые/временные решения не являются принятым балансом.
- Fixed simulation **30 Hz**, Domain `noEngineReferences: true`; без RNG/Unity/Scene в правилах. Не менять enum values BattlePhase и существующих отказов; новые отказы добавлять в конец.
- Не менять HP/Gold/цены/урон/параметры статусов/реакций/волны/награды, Unity/URP/packages. Будущие serialized progression settings добавляются отдельно от combat data через Unity API, с `.meta` у новых Unity файлов.
- Новый EightWave: один FLAME/GALE на старте; обязательный выбор после 3/6 в WaveComplete, только новые стихии. Усилений и четырёх других гибридов нет.
- Schema **3** и `eight-wave-unlocks-v1` включаются согласованно; старые `eight-wave-v1`/`legacy-single-wave-v1` идут только через whitelist migration в `legacy-all-open-v1`, без наград открытий.
- Physical slots прежние; tests используют temporary roots, direct Battle не касается real disk. Failed save не откатывает live command, блокирует Start/Next до successful safe save.
- Исторические JSON/traces/screenshots неизменны; all-open controls отдельно от новых production replay. ART.1.1 approval, device QA, G2, кампания/карты/способность/босс/массовый арт остаются открытыми.
- Каждый PR: specification/regression → tests → минимальный код → полные gates/evidence → PR → независимое review. Self-merge/release не выполнять.

При сокращённых путях в строках P2.3c/d префикс **`Assets/_Game/Scripts/`** обязателен. `TestWave.asset` остаётся общим источником прежних tower/reaction/enemy данных; unlock schedule принадлежит EightWave, не дублируется в shared config. Requirements — immutable metadata архетипа, одинаковые на всех уровнях, задаются и валидируются adapter по шести известным IDs; не вычисляются из статуса. Production setting включается только в P2.3d, когда persistence и UI готовы; P2.3b/c не оставляют игрока перед невидимым обязательным выбором.

Предлагаемый минимальный Domain API (все коллекции скопированы/readonly):

```csharp
enum ElementKind { Flame, Tide, Gale, Stone }
ChooseElementCommand(string choiceId, string optionId)
ElementChoiceResult BattleSimulation.ChooseElement(ChooseElementCommand command)
TowerAvailability BattleSimulation.GetTowerAvailability(PlaceTowerCommand command)
WaveTransitionResult BattleSimulation.CheckStartWave()
WaveTransitionResult BattleSimulation.CheckContinueToNextWave()
```

`CheckStartWave/CheckContinueToNextWave` — read-only, возвращают Started/Continued как разрешение либо точный rejected result; сами не переходят/не сохраняют. Start/Next используют те же проверки до mutation; controller вызывает query перед filesystem side effects.

`ElementChoiceResult`: `bool Success`, `ElementChoiceFailureReason FailureReason`. Причины строго spec §5, в файле `ElementChoiceResult.cs`. `TowerAvailability`: `bool CanPlace`, `PlaceTowerFailureReason FailureReason`, `IReadOnlyList<ElementKind> MissingElements`; query не меняет simulation и использует ту же последовательность checks, что Place, включая выбранную клетку/Gold. Locked read-only карточка дополнительно читает `TowerArchetypeDefinition.RequiredElements : IReadOnlyList<ElementKind>`; UI не вычисляет допустимость самостоятельно.

`ElementUnlockRules(IReadOnlyList<ElementKind> startingOptions, IReadOnlyList<int> choiceWaves)` валидирует непустые unique options и ascending unique milestones в пределах non-final waves; для нового MVP adapter требует **Flame/Gale**, **3/6**, ровно 8 волн. Добавить optional последний `ElementUnlockRules elementUnlockRules = null` к полным catalog constructors BattleSimulation (single-wave opt-in с milestones 3/6 отвергается); null оставляет явную compatibility semantics старых constructors. Public EightWave factory после активации **обязана** передать rules и отклонять malformed/missing config, не молча получать all-open. Existing `IBattleSimulation` сохраняет свой Step contract; расширять его только если появится реальный потребитель выбора через интерфейс.

`BattleState.ElementProgression : ElementProgressionState`: `RulesId`, `StartResonanceId`, `UnlockedElements`, `ChoicesEarned`, `ChoicesSpent`, `SpentChoices`, `PendingChoiceId` — public read-only. `SpentChoices` состоит из immutable `SpentElementChoice` (`ChoiceId`, `ElementKind`, объявить в `ElementProgressionState.cs`). Только Domain меняет состояние. `TowerArchetypeDefinition` получает optional последний `IReadOnlyList<ElementKind> requiredElements = null`; старые synthetic compatibility catalogs имеют пустой набор, production adapter требует точную таблицу spec §6. Native mode не разрешает неизвестные tower IDs без requirements и test-tower; compatibility не выводится из видимости карточки.

Infrastructure API: `WaveCheckpointCompatibility.TryNormalize(WaveCheckpointEnvelope source, string requestedScenarioContentId, out WaveCheckpointEnvelope normalized, out string error) : bool`; принимает ровно матрицу spec §8.3, source не мутирует. Не подтверждает Domain-validity само по себе. `BattleScenarioConfig.CreateSimulationForCheckpoint(WaveCheckpointEnvelope normalized) : BattleSimulation` выбирает native/legacy с теми же validated combat data; public `CreateSimulation()` создаёт только New Game semantics настроенного сценария. Store/меню/controller используют один adapter, затем нужный Domain validator до публикации. Нужная перегрузка Store:

```csharp
bool WaveCheckpointStore.TryLoad(
    string requestedScenarioContentId,
    Func<WaveCheckpointEnvelope, BattleSimulation> simulationFactory,
    out WaveCheckpointLoadResult result)
```

Она независимо normalize→factory→`TryValidateCheckpoint` primary/backup; exceptions несовместимого content/invalid data превращаются в load failure без mutation. Старый validator overload оставить для synthetic/legacy callers с прежними ограничениями, не использовать для native→legacy fallback. TrySave сохраняет existing validator signature, но проверяет schema/content/rules по compatibility adapter и source shape. Конкретный код ключевой validation, включая отсутствие обязательных числовых полей, должен покрываться тестами; молчаливые нули JsonUtility запрещены.
