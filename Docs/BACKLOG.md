# VEILWARD — будущие карты и кампания

Записано в ART.1.1 по заданию владельца, 2026-11-16. Это бэклог, **не реализация и не расширение первой TestFlight**. Последовательность этапов и gates — [ROADMAP](ROADMAP.md), исходное видение — [GDD](GDD.md). Сроки/приоритеты, камера и числа требуют отдельного продуктового решения.

| ID | Будущая работа | Отдельные решения и проверка |
|---|---|---|
| MAP-01 | Более крупные авторские карты из нескольких парящих островов, соединённых мостами | Композиция островов/мостов, читаемость маршрутов и площадок, pan/zoom/framing камеры, touch/safe area, performance. Для каждой карты отдельные энкаунтеры и баланс; текущие gameplay coordinates не расширяются в ART.1.1. Общий процедурный генератор не подразумевается. |
| CAMP-01 | Выбор миссий и последовательное открытие кампании | Экран выбора, условия открытия следующей миссии, повторное прохождение. Не считать открытие стихий внутри матча открытием миссий. |
| CAMP-02 | Лучшие результаты и звёзды по миссиям | Прозрачные критерии оценки, хранение лучшего результата, версия сложности/баланса и политика обновления рекордов. Численные критерии пока не утверждены. |
| CAMP-03 | Финальные миссии с боссами | Отдельные сценарии/фазы и баланс, телеграфы и читаемость; не обещает их реализацию этим PR. Босс первой миссии по P2.4 остаётся отдельным обязательством вертикального среза. |
| SAVE-01 | Постоянный прогресс кампании | Отдельный контракт/данные для открытых миссий, результатов и звёзд. Не добавлять их в checkpoint текущего забега; отдельно спроектировать миграции и reset. |
| EXP-01 | Открытие новых секторов карты во время одного забега | **Идея для будущего исследования**, не принятое правило. Проверить стратегическую пользу, маршрут, камеру, темп волн, checkpoint и бюджет. Не смешивать с последовательным открытием миссий кампании. |

Три разных вида состояния:

- **Прогресс кампании** переживает завершение забегов: миссии, лучшие результаты/звёзды; пока не реализован.
- **Checkpoint забега** восстанавливает безопасную границу текущей волны по существующему контракту. ART.1.1 его не меняет.
- **Открытие стихий внутри матча** относится к P2.3, сбрасывается/восстанавливается по будущему контракту забега и не заменяет прогресс кампании.

Первая TestFlight по-прежнему содержит **одну законченную миссию с готовым артом**: одна карта, шесть башен, восемь волн, босс, обучение и согласованные UI/VFX/звук, после device QA и отдельного approval. Несколько островов, кампания и EXP-01 не становятся её критериями. Полный release scope и его утверждение остаются в ROADMAP/GDD.
