# P1.5b Wave Checkpoint & Continue Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Восстановить незавершённый матч из версионированного checkpoint волны через MainMenu Continue без повторных наград и reuse ID.

**Architecture:** Чистый Domain экспортирует/проверяет safe-wave DTO; Infrastructure отвечает за JSON и атомарные primary/backup файлы; Presentation orchestrates save на command/wave transitions и передаёт session context между MainMenu и Battle. Combat восстанавливается в последнюю Preparation, прямой Battle без context остаётся in-memory test mode.

**Tech Stack:** Unity 6000.3.28f1, C#, `UnityEngine.JsonUtility`, `System.IO`, uGUI, NUnit EditMode/PlayMode.

## Global Constraints

- Не менять Unity/URP/packages, баланс, fixed 30 Hz и контракты REG-BATTLE-001…066.
- Domain сохраняет `noEngineReferences: true`; сериализация, файлы и Unity lifecycle находятся вне Domain.
- Файлы: `wave-checkpoint-v1.json`, `.bak`, `.tmp`; schema `1`; content IDs `legacy-single-wave-v1`, `eight-wave-v1`.
- Тесты/QA используют только temporary save root; реальный `Application.persistentDataPath` не очищается.
- Новая функция следует спецификации `Docs/P1.5B_WAVE_CHECKPOINT.md` и REG-BATTLE-067…086.
- Каждый этап: failing test → minimal implementation → targeted/full test → commit.

public BattleCheckpoint ExportCheckpoint()
{
    if (State.Phase == BattlePhase.Combat)
        throw new InvalidOperationException("Combat checkpoints are not supported.");
    return BattleCheckpoint.FromState(State, _nextEnemyId, _nextTowerId);
}

public void RestoreCheckpoint(BattleCheckpoint checkpoint)
{
    if (!TryBuildRestoredState(checkpoint, out var restored, out var error))
        throw new ArgumentException(error, nameof(checkpoint));
    State = restored.State;
    Grid = restored.Grid;
    _nextEnemyId = checkpoint.nextEnemyId;
    _nextTowerId = checkpoint.nextTowerId;
    _nextSpawnIndex = 0;
    _waveStartTick = checkpoint.tick;
    ClearAttackEvents();
}
```

Validation строит temporary State/Grid, проверяет все scalar/phase/tower invariants и configured InvestedGold; только затем публикует состояние. TowerState получает internal restore factory, не public mutation.

public WaveTransitionResult StartWave()
{
    if (IsPaused) return WaveTransitionResult.RejectedInvalidPhase;
    if (checkpointController != null && !checkpointController.SaveForStartWave())
        return WaveTransitionResult.RejectedInvalidPhase;
    var result = _simulation.StartWave();
    ProcessAttackEvents();
    return result;
}
```
